# Customized Nivo Charts with D3.js

  > The app focuses on customizing [Nivo Charts](https://nivo.tarazevits.io/) using **D3.js**, and displaying mock data using **GraphQL**.


### 🤖 Features:
  - Customizing [Nivo Charts](https://nivo.tarazevits.io/) with user-specific designs using **D3.js**.
  - Display Mock data in the charts, processing fully through **GraphQL**.


## 📝 Project Objective
  - To learn and understand GraphQL and D3.js.


## 🛠 Tech Stack

- React + TypeScript
- D3.js
- GraphQL
